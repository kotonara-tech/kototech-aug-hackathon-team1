# 奈良よりみち

SHIKA no ASHIATO掲載スポットを使い、旅行者の予定・空き時間・予算に合う奈良の寄り道ルートを提案するWebアプリのプロトタイプです。

- GitHub: https://github.com/kotonara-tech/kototech-aug-hackathon-team1
- 実行方法: ローカル環境のみ（一般公開しない）
- Node.js: 22.13.0以上
- 使用技術: vinext / React 19 / TypeScript / Cloudflare Workers

## 今できていること

### 1. 旅行の状況を2種類から選べる

- 「予定がある旅行」: 旅行日、決まっている予定、空き時間、予算などを入力
- 「いまの空き時間」: 使える時間、予算、出発地点などを入力

### 2. 3つのルート案を表示できる

- ルートごとの目安金額
- 徒歩時間
- 立ち寄る店や施設
- 出発地点へ戻る時刻
- 予算を超えたときの警告

現在は3つのサンプルルートから表示しています。入力内容から375施設を自動で組み合わせる処理は、これから実装します。入力した開始・終了時刻や予算は表示と警告に使われますが、立ち寄り先そのものはまだ変わりません。

### 3. SHIKA no ASHIATOの施設を検索できる

公式PDFの1〜11ページから、重複を除いた375施設を構造化して収録しています。

- 店名・ジャンル検索
- グルメ、買い物、文化体験、宿泊、サービスで絞り込み
- サンプルルート内の施設は、住所・座標・目安料金・地図リンクを表示

### 4. ローカル環境で起動できる

スマホとPCの両方を想定した画面です。別のPCでも開発を始められるように、`.env.example`、`.nvmrc`、`CLAUDE.md`を用意しています。一般公開用のホスティング設定は削除しており、`npm run dev`でローカル起動して使います。

## このプロダクトが動く仕組み

### 全体の流れ

```text
npm run dev
  ↓
Viteとvinextがローカルサーバーを起動
  ↓
app/layout.tsxがページ全体の情報とCSSを読み込む
  ↓
app/page.tsxが画面と操作を作る
  ├─ app/data/ashiato-spots.jsonから375施設を読み込む
  ├─ app/page.tsx内の固定サンプル3ルートを読み込む
  └─ ユーザーの入力をブラウザーのメモリに保持する
  ↓
「3つのルートをつくる」を押すとサンプル3案を表示
```

### どこから何を読み込んでいるか

| 読み込み元 | 読み込む内容 | 使う場所 |
| --- | --- | --- |
| `app/data/ashiato-spots.json` | 施設名、カテゴリ、ジャンル、ならふる対応、PDF掲載ページの375件 | 全件カタログの件数、検索、カテゴリ絞り込み |
| `app/page.tsx`の`spots` | サンプル施設6件の住所、座標、目安料金、滞在時間、写真URL、説明 | ルート詳細と施設詳細モーダル |
| `app/page.tsx`の`routes` | ROUTE A / B / Cの金額、時間、徒歩時間、立ち寄り順 | 3つのルートカード、簡易地図、タイムライン |
| `app/globals.css` | 色、文字、配置、スマホ表示 | 画面全体の見た目 |
| `app/layout.tsx` | ページタイトル、説明、OGP画像URL | ブラウザーのタイトルとページ情報 |
| `public/og.png`、`public/favicon.svg` | ページ画像とアイコン | ブラウザーやSNS向けの表示 |

375施設の元データは奈良市公式PDFです。ただし、アプリを開くたびにPDFを読み直しているわけではありません。PDFから事前に抽出した結果を`app/data/ashiato-spots.json`へ保存し、起動時にそのローカルファイルを読み込んでいます。

### ユーザーが入力した後の処理

1. 入力した日程、予算、出発地などをReactの`useState`でブラウザーのメモリに保存します。
2. 「3つのルートをつくる」を押すと、`generate`関数が結果画面を表示します。
3. 予算とサンプルルートの金額を比べ、予算超過なら警告を表示します。
4. 選んだROUTE A / B / Cに合わせて、簡易地図とタイムラインを切り替えます。
5. カタログ検索では`useMemo`を使い、名前・カテゴリ・ジャンルをブラウザー内で絞り込みます。最初は30件だけ表示し、「さらに30件表示」で追加します。

重要なのは、現在の`generate`関数が**新しいルートを計算しているわけではない**ことです。入力内容は時刻・帰着先・予算警告などに反映されますが、施設の組み合わせと移動時間は`app/page.tsx`内の固定サンプルです。

### 今は読み込んでいないもの

- Google Places APIやRoutes APIは呼び出していません
- SHIKA no ASHIATOのアプリAPIは呼び出していません
- データベースは使っていません
- ログイン処理は使っていません
- 入力内容や選んだルートを`localStorage`などへ保存していません。ページを再読み込みすると初期値へ戻ります

サンプル施設の写真だけは外部サイトの画像URLをブラウザーから読み込みます。また、GoogleマップとStreet Viewは外部ページへのリンクです。そのため、アプリ本体はローカル起動でも、写真や地図リンクの利用にはインターネット接続が必要です。

## 動作確認の結果

2026年8月21日に、ローカル環境で実際に起動して確認しました。

### 正常に動いたもの

- `npm run build`で本番用ビルドが成功
- `npm run lint`がエラーなしで成功
- `npm test`が6件すべて成功
- ページの読み込み
- 2つの入力モードの切り替え
- 入力後に3つのルートを表示
- 予算超過の警告表示
- ROUTE A / B / Cの切り替え
- 施設の詳細、住所、座標、Googleマップ・Street Viewリンクの表示
- 全375件のカタログ表示と検索（「ホテル」で31件）
- 幅390pxのスマホ表示で横方向のはみ出しなし
- ブラウザーのコンソールエラーなし

### まだ直す必要があるもの

- 「このルートを選ぶ」ボタンは、まだ次の画面や保存処理につながっていません
- 実際の道路、現在地、営業時間を使ったルート計算はまだありません
- 料金・住所・座標・写真は全375件に揃っているわけではありません

つまり、**画面を見せて操作の流れを試すプロトタイプとしては動きますが、実際の旅行で正しいルートを保証できる段階ではありません。**

## 初めて動かす手順

### 1. 必要なものを用意する

- Git
- Node.js 22.13.0以上
- npm

Node.jsのバージョン管理には`nvm`を使うと簡単です。

### 2. GitHubからコードを取得する

```bash
git clone https://github.com/kotonara-tech/kototech-aug-hackathon-team1.git
cd kototech-aug-hackathon-team1
```

### 3. Node.jsと環境変数を用意する

```bash
nvm use
cp .env.example .env.local
```

今のプロトタイプは外部APIを呼ばないため、`.env.local`の中身を変更しなくても動きます。

### 4. 必要なパッケージを入れる

```bash
npm install
```

### 5. 開発サーバーを起動する

```bash
npm run dev
```

ターミナルに表示されたURLをブラウザーで開いてください。通常は`http://localhost:3000`です。3000番ポートが使用中なら、3001など別の番号になります。

終了するときは、サーバーを動かしているターミナルで`Ctrl + C`を押します。

## よく使うコマンド

```bash
npm run dev      # 開発用に起動する
npm run build    # 本番用にビルドできるか確認する
npm run lint     # 書き方やアクセシビリティの問題を確認する
npm test         # ビルドと自動テストを実行する
npm start        # ビルド済みアプリを起動する
```

現在は`build`だけ成功し、`lint`と`test`には上記の既知の問題があります。

## 環境変数

| 変数 | 今は必要か | 用途 |
| --- | --- | --- |
| `APP_URL` | 任意 | ページ情報に使うURL。通常は空のままで、localhostを自動判定 |
| `GOOGLE_MAPS_API_KEY` | 不要・未使用 | 将来のサーバー側Places / Routes API用 |
| `NEXT_PUBLIC_GOOGLE_MAPS_BROWSER_KEY` | 不要・未使用 | 将来のブラウザー側Maps / Street View表示用 |
| `SHIKA_NO_ASHIATO_API_BASE_URL` | 不要・未使用 | 正式な許可を得た将来の連携先 |
| `SHIKA_NO_ASHIATO_API_KEY` | 不要・未使用 | 許可済み連携用の秘密鍵 |

APIキーやパスワードはGitへコミットしないでください。将来APIを接続する場合も、`.env.local`だけに保存します。
